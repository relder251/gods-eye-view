macOS Keychain

      

        On macOS, ./scripts/dev-fresh.sh reads keys straight from the Keychain, so they never
        touch a file in the repository. Run the command for a provider, paste the key at the prompt, and
        launch with the script instead of npm run dev. A Keychain value outranks
        .env — which is exactly the situation this page reports as
        OVERRIDDEN.
      

      

      

        
      

    


    

      
Before you leave a key running

      

        The dev server is a key broker: anything that can reach it can spend the quota on every credential
        it holds. It binds to localhost for that reason, and this setup page answers only
        requests from this machine even when you opt into HOST=0.0.0.0. App-level throttles
        (GEV_RATELIMIT_OPENAI_PER_MIN, GEV_RATELIMIT_GOOGLE_PER_MIN) are guards,
        not billing caps — set provider-side budgets for the two metered accounts before a long session.
        Set GEV_SETUP_READONLY=1 to keep this page's links and status but forbid it writing
        .env at all.
